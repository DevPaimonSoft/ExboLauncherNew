# EXBO Launcher New

Нативный лаунчер для Windows, написанный на Rust с интерфейсом Slint.

Работает без установленного официального лаунчера EXBO. Поддерживает авторизацию, установку, обновление и запуск игры, управление аккаунтами и настройку производительности.

## Возможности

- Авторизация EXBO, Steam, двухфакторная аутентификация и сохранение сессии.
- Установка, обновление, проверка и восстановление игровых файлов.
- Загрузка через HTTP и P2P с возможностью паузы и ограничения скорости.
- Автоматическая загрузка необходимой Java и античита.
- Оптимизация JVM, настройка оперативной памяти и выбор ядер процессора.
- Проверка сетевых туннелей и выбор оптимального подключения.
- Импорт и экспорт настроек оптимизации в JSON.
- Управление игровыми серверами и просмотр их состояния.
- Поддержка нескольких аккаунтов.
- Работа в системном трее и автозапуск с Windows.
- Интерфейс на русском и английском языках.
- Автоматический импорт данных из прежней установки EXBO.
- Проверка обновлений лаунчера из указанного источника.

## Сборка

Для сборки необходимы Rust, Visual Studio Build Tools с компонентами C++ и Windows SDK.

```powershell
.\scripts\build.ps1 -Release
```

Запуск собранного лаунчера:

```powershell
.\dist\ExboLauncherNew\.exe
```

Для запуска из исходников:

```powershell
cargo run --locked
```

Готовый лаунчер не требует отдельной установки Java или официального лаунчера EXBO.

## Использование

При первом запуске войдите в аккаунт, выберите сервер и папку установки игры, затем нажмите «Установить».

Если на компьютере обнаружена прежняя установка EXBO, лаунчер может импортировать настройки, установленные клиенты и сохранённую сессию.

Данные приложения хранятся в:

```text
%LOCALAPPDATA%\ExboLauncherNew
```

Для использования отдельного каталога данных:

```powershell
ExboLauncherNew.exe --data-dir "D:\LauncherProfile"
```
