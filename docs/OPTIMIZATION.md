# Оптимизация EXBO Launcher New

Встроенная оптимизация игры позволяет настроить JVM, использование процессора и сетевое подключение.

Настройки доступны во вкладке «Оптимизация» без необходимости входа в аккаунт. Изменения применяются при следующем запуске игры.

## JVM-оптимизация

Лаунчер поддерживает автоматическую и ручную настройку параметров Java для повышения стабильности и производительности игры.

Доступные возможности:

- Автоматический подбор параметров под характеристики компьютера.
- Готовые профили G1GC и Aikar.
- Настройка выделяемой оперативной памяти.
- Управление сборщиком мусора и потоками GC.
- Настройка JIT-компилятора и кэша кода.
- Дополнительные параметры памяти и Java.
- Просмотр создаваемых JVM-флагов.
- Импорт и экспорт профилей JSON.

### Как включить

1. Откройте вкладку «Оптимизация».
2. Нажмите «Авто» или выберите профиль Aikar.
3. При необходимости измените параметры вручную.
4. Включите «Включить JVM-профиль».
5. Нажмите «Сохранить и применить».

Автоматический подбор учитывает оперативную память, количество доступных потоков процессора и скорость памяти.

По умолчанию оптимизация отключена. При её включении объём памяти игры управляется выбранным профилем.

Настройки затрагивают только запуск игры через EXBO Launcher New и не изменяют глобальные параметры Java или Windows.

## Настройка процессора

В разделе «Оптимизация → Процессор» можно выбрать логические процессоры, которые разрешено использовать игре.

Для настройки включите ограничение CPU, отметьте нужные процессоры и сохраните изменения.

По умолчанию ограничение отключено, а распределением нагрузки управляет Windows.

Настройка работает независимо от JVM-профиля и применяется при следующем запуске игры. Поддерживаются системы с одной группой процессоров, до 64 логических CPU.

Ограничение количества процессоров не гарантирует увеличение FPS.

## Оптимизация сети

Раздел сети позволяет проверить доступные туннели EXBO и выбрать подключение с наименьшей задержкой.

Поддерживаются регионы RU, EU, NA, SEA и NEA.

Возможности:

- Получение списка доступных туннелей.
- Измерение задержки через UDP.
- Сравнение медианы, P90 и потерь ответов.
- Оценка стабильности подключения.
- Автоматический выбор лучшего туннеля.
- Ручной выбор адреса сервера.
- Отмена и повторное проведение измерений.

Для каждого туннеля выполняется 10 проб. При сравнении учитываются задержка, стабильность и количество ответов.

### Как настроить

1. Откройте «Оптимизация → Сеть».
2. Выберите регион.
3. Нажмите «Найти / измерить узлы».
4. Дождитесь окончания проверки.
5. Нажмите «Выбрать лучший» или выберите туннель вручную.
6. Сохраните изменения.

Сетевые настройки работают независимо от JVM-оптимизации.

Результаты измерений не являются гарантией такой же задержки непосредственно в игре.

## Импорт и экспорт

Настройки оптимизации можно сохранять в JSON и переносить между компьютерами.

- «Импорт JSON» — загрузка готового профиля.
- «Экспорт JSON» — сохранение всех настроек оптимизации.
- «Экспорт JVM JSON» — сохранение только параметров Java.
- «Отменить изменения» — возврат к последним сохранённым настройкам.
- «Сбросить настройки оптимизации» — восстановление настроек по умолчанию.

Экспортируемые профили не содержат паролей, токенов авторизации и данных игровых аккаунтов.

## Восстановление старых настроек

Если ранее использовался внешний JVM-оптимизатор с IFEO-перехватчиком, его настройки могут конфликтовать со встроенной оптимизацией.

В разделе «Оптимизация → Справка» доступна функция «Сохранить скрипт восстановления».

Для проверки записей реестра:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\recover-legacy-optimizer.ps1
```

Для удаления обнаруженных записей после проверки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\recover-legacy-optimizer.ps1 -Apply
```

Перед удалением создаётся резервная копия. Изменения требуют подтверждения пользователя и прав администратора.

Лаунчер самостоятельно не удаляет записи реестра.

## Важно

Оптимизация не гарантирует увеличение FPS на каждом компьютере. Результат зависит от процессора, оперативной памяти и текущих настроек системы.

Рекомендуется начинать с автоматического профиля и изменять дополнительные параметры только при необходимости.
