# Автономная работа EXBO Launcher New

EXBO Launcher New работает без установленного официального лаунчера EXBO и отдельной установки Java. Все необходимые служебные компоненты встроены в исполняемый файл.

## Первый запуск

1. Скачайте и запустите `ExboLauncherNew.exe`.
2. Авторизуйтесь через EXBO или Steam.
3. Выберите игру и каталог установки.
4. Нажмите «Установить» и дождитесь завершения загрузки.
5. Запустите игру.

Java и античит загружаются вместе с игровым клиентом.

Если ранее был установлен официальный лаунчер EXBO, доступен импорт установленных игр и сохранённой сессии. Наличие прежней установки необязательно.

## Хранение данных

Настройки, игровые файлы и служебные компоненты по умолчанию хранятся в:

```text
%LOCALAPPDATA%\ExboLauncherNew
```

Каталог установки игры можно изменить в интерфейсе.

Встроенные служебные компоненты автоматически проверяются и восстанавливаются при необходимости.

Для восстановления компонентов используйте «Настройки → Проверить / восстановить компоненты».

Для проверки игровых файлов доступны кнопки «Проверить» и «Восстановить все файлы».

## Диагностика

Для проверки работы без импорта прежней установки:

```powershell
.\ExboLauncherNew.exe --no-legacy-import --data-dir "D:\CleanLauncherProfile" --diagnose
```

Параметр `--no-legacy-import` отключает импорт данных из прежнего лаунчера при создании нового профиля.

Диагностика проверяет служебные компоненты и не выполняет авторизацию или загрузку игры.

## Совместимость

Лаунчер использует авторизацию и игровые манифесты EXBO, поддерживает проверку файлов и штатный запуск античита.

При изменении протоколов EXBO может потребоваться обновление лаунчера.
