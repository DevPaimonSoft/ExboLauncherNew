# Перенос EXBO Launcher на Rust

EXBO Launcher New — нативная реализация лаунчера EXBO на Rust с интерфейсом Slint.

Основные механизмы авторизации, загрузки, обновления и запуска игры перенесены на основе анализа оригинального Java/Kotlin-лаунчера.

Официальный лаунчер и отдельная установка Java не требуются. Служебные компоненты встроены в EXE.

Инструкция по первому запуску: [AUTONOMOUS.md](AUTONOMOUS.md).

## Реализация

Для анализа оригинального `launcher.jar` использовались CFR и javap. Изучены API, авторизация, загрузка файлов, игровые манифесты, настройки и параметры запуска.

Основная логика реализована на Rust без запуска оригинального Java-лаунчера.

| Модуль | Назначение |

## Совместимость

Реализованы основные механизмы оригинального лаунчера:

- Авторизация EXBO и обработка сохранённых сессий.
- Поддержка challenge SHA-1 и BCrypt.
- Совместимость с игровыми API и bootstrap.
- Чтение бинарных игровых манифестов EXBO.
- Проверка целостности файлов по SHA-1.
- HTTP-загрузка с докачкой и резервная P2P-загрузка.
- Поддержка `true_path`, повторяющихся хешей и оригинального torrent infohash.
- Подготовка параметров запуска Java и игровой сессии.
- Работа с HWID через встроенный нативный компонент.
- Импорт настроек и установленных игр.
- Защита сохранённых сессий через Windows DPAPI.

Для загрузки сначала используется HTTP. При необходимости и доступности P2P применяется резервная загрузка. Раздача работает только с проверенными файлами.

## Проверки

Проведены следующие проверки:

- Сборка проекта и проверка Rust/Slint.
- Обработка API, challenge и BCrypt.
- Чтение игровых манифестов.
- Загрузка, докачка и восстановление файлов.
- Проверка целостности и обработка повреждённых данных.
- Передача файлов через локальное P2P-соединение.
- Сохранение и восстановление сессий.
- Работа встроенного HWID-компонента.
- Проверка обновлений по SHA-256.
- Отрисовка основных экранов интерфейса.

## Ограничения

Авторизация на реальных серверах EXBO, вход через Steam, двухфакторная аутентификация и запуск игры требуют дополнительной проверки под действующим аккаунтом.

Полная загрузка игрового клиента и некоторые системные операции Windows отдельно не проверялись.

Старые файлы состояния libtorrent не импортируются. Существующие игровые файлы проверяются повторно.

Обновления Rust-лаунчера распространяются через отдельный настраиваемый источник, независимо от официального обновлятора EXBO.

При изменении API, bootstrap или игровых протоколов может потребоваться обновление проекта.
